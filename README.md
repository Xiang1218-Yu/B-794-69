# 3D 城市场景页面

这是一个基于 **Three.js** 开发的高性能程序化 3D 城市场景项目。

## 🚀 快速启动

1. 本项目为单文件应用，直接使用浏览器打开 `index.html` 即可运行。
2. 建议开启浏览器的 **硬件加速** 以获得最佳性能体验。

## 🎮 操作说明

- **旋转视角**：鼠标左键拖拽 / 移动端单指滑动
- **平移视角**：鼠标右键拖拽 / 移动端双指平移
- **缩放**：鼠标滚轮 / 移动端双指缩放
- **控制面板**：使用右上角（或移动端底部）的面板调整场景参数。

## 🌟 核心特性

- **高性能实例化渲染引擎 (Instancing Engine)**：
  - 项目深度利用 `THREE.InstancedMesh` 技术，将数以万计的窗户、植被、路灯和车流合并至极少数的渲染指令（Draw Calls）中。
  - 即使在移动端或低配设备上，也能保持稳定的运行表现。

- **程序化城市生成**：
  - 动态生成 180+ 栋具有随机高度、层级结构和外立面材质的大楼。
  - 自动化构建城市路网、双向交通系统、水道桥梁。

- **电影级视觉效果**：
  - **动态昼夜过渡**：一键切换白天与黑夜模式。黑夜模式下拥有模拟霓虹灯闪烁、窗口呼吸感发光以及流动的彩色车流。
  - **后期处理**：集成了 `UnrealBloomPass` 辉光效果，为城市夜景增添赛博朋克风格的朦胧质感。
  - **程序化纹理**：立面、绿植和草地贴图均通过 Canvas 程序化生成，有效减少了外部资源依赖。

- **极致响应式交互 UI**：
  - **磨砂玻璃控制面板**：提供模型缩放、场景旋转、相机视角切换等实时控制项。
  - **移动端深度优化**：控制面板在移动端自动转换为可折叠的“手柄”式设计，最大化视野空间。

## 🛠️ 技术栈

- **核心引擎**：Three.js (r160)
- **后期处理**：EffectComposer (Bloom Pass)
- **交互控制**：OrbitControls
- **前端技术**：HTML5, CSS3, JavaScript (ES6+), WebGL
